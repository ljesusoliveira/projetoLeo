## Ao publicar no YouTube

- No YouTube Studio, em **Vídeo relacionado**, escolha o vídeo longo. Assim o link clicável aparece no Short, que é para onde o texto final aponta.
- O Short termina emendando com o começo, para repetir sozinho.

## Arquivos técnicos

Os scripts estão em `scripts/`. `edl.json` é o roteiro (trechos do vídeo longo, enquadramento e textos). `build.sh` refaz tudo a partir do vídeo longo salvo como `scripts/original.mp4`.
